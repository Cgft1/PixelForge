PixelForge 3.7 — версия для Windows

Для локальной сборки: установите Node.js 20 или новее, затем запустите BUILD_EXE.bat.

Автоматическая сборка: GitHub → Actions → Build PixelForge Windows EXE. После успешного запуска скачайте артефакт PixelForge-Windows-EXE.

Это portable EXE, установщик не требуется.
